# 长安十二时辰 · 灯火如昼（v3 · MBTI 人格测评）

把马伯庸原著《长安十二时辰》改编成多主角剧情冒险游戏：浏览器单页 HTML，覆盖完整十二时辰主线，剧情分支 + 多结局 + **MBTI 人格测评**。

> ⚠️ **版权声明**：本游戏仅用于个人学习与原型开发。《长安十二时辰》原作著作权归马伯庸先生与相关方所有。**请勿用于任何商业用途或公开发布。**

## 运行

```bash
cd chang
python -m http.server 8010
# 浏览器打开 http://localhost:8010/
```

也可以用 Node：`npx --yes serve .`

## 玩法

- **十二时辰**刻度顶栏高亮当前时辰；走过自动点亮。
- 每章含 2-3 个**关键抉择**：
  - 每个选项可触发：剧情跳转 / 标记 flag / 获得线索 / 改变某角色信任度 / **为 6 个人格维度加分**
- 走完**亥时 · 抉择**，根据之前的 flag + trust 触发**三结局之一**：
  - **血色长安**：拔刀拼死一战
  - **灯火如昼**：为人而活，化解仇怨
  - **未竟之局**：以理化仇，长安却没被保住
- 结局页同时呈现**长安人格画像**（见下）

## 人格测评：MBTI（v3 核心）

### 4 个维度（映射到长安语境）
| 维度 | 长安语境 | 左 / 右 |
|---|---|---|
| **E / I** | 调兵遣将广结人脉 ↔ 独自追查深思独行 | 外向 / 内向 |
| **S / N** | 查户籍看脚印重物证 ↔ 推断动机看朝堂大局 | 实感 / 直觉 |
| **T / F** | 就事论事冷酷决断 ↔ 顾及人情宽恕共情 | 思考 / 情感 |
| **J / P** | 守计划执行到底 ↔ 见机行事随机应变 | 判断 / 知觉 |

- 每个抉择在 4 个维度各有 **-3 ~ +3** 的倾向分（正值偏 E/S/T/J，负值偏 I/N/F/P）
- 结果按 **偏好强度** 显示：`E 68% / I 32%` 这样的双向百分比条
- 每维取较高一侧 → 组合成 **4 字母类型**（如 `ENTJ`）

### 匹配逻辑（三层）
1. **主匹配**：与你 MBTI 型相同的那位人物（16 型 ↔ 16 人物确定性对应）
2. **契合度**：你的四维强度与该人物向量的平均偏差 → `契合度 76%`
   - 契合度高 = 你是这个型的"典型样本"；偏低 = 你处在这个型的边缘
3. **次席**：用 z-score 比较"特质形状"，给出第二接近的人物作为补充视角

### 随机 24 局分布（验证测评有效性）
```
E/I: E=20  I= 4   | 左侧占比区间 41%~77%
S/N: S=10  N=14   | 左侧占比区间 33%~65%
T/F: T= 9  F=15   | 左侧占比区间 32%~62%
J/P: J=20  P= 4   | 左侧占比区间 44%~76%
出现 9 种不同类型，8 个字母全部可达
```
> E / J 偏多是剧情本身决定的（张小敬的故事偏行动与决断），I / P 均可达。

## 注意事项

- 测评结果仅供娱乐与自我觉察，**不构成心理诊断**。
- 路径长度不同时（不同分支），达成率基于你**实际经过**的节点计算，因此跨局可比。
- 改动 `scenes.js` 的选项顺序时，必须同步改 `traits.js` 中对应场景的 `CHOICE_TRAITS`，否则 verify 会报错。
