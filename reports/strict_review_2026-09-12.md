# 严格检查报告（2026-09-12）

结论：当前版本可以完成游戏，但仍存在叙事连续性、结局展示和计分解释错误，不能据现有自动化全绿判定内容已验收。本次只检查并记录，未修改业务代码或剧情。

## 验证范围与证据

- `npm run test:all` 退出码 0；85 个节点、66 个选项、59 个过场、4 个结局均在结构检查范围内。3000 局随机模拟覆盖全部结局。
- 实际启动本地临时 HTTP 服务，用系统 Chromium 浏览器无头访问两个页面：图鉴正常生成卡片；主页面全选首项，38 次页面推进、20 次抉择后抵达血色长安，类型 ESTJ，无页面运行时异常。
- 浏览器实际读到 `T undefined`、`J undefined` 等标签；实际图鉴将劝降两版开场连续显示，触发条件遗漏。控制台中文输出编码损失不作为页面乱码证据。
- 对实际模块与图鉴脚本做隔离求值，复核条件翻译和正文拼接；另外用固定种子 912、LCG 参数 1664525/1013904223 模拟 3000 局，复现计分展示问题。
- 以下设定问题以仓库内部相互矛盾为判据，未做原著、剧版或历史法律的外部查证。未执行全套浏览器冒烟，也未做移动端视觉验收。

## 必须优先修复

### 1. 图鉴把互斥的两版结局拼成同一段（P1）

位置：`results.html:449`，`src/data/scenes.js:2171` 附近。

`resolveText(sc, () => true)` 同时放行 `flagsAll: ['final_empathy']` 与 `flagsNone: ['final_empathy']`。未竟之局里龙波先听完共情台词、已经松手，又重新听一次“我替你把仇报了”。图鉴还将两段错误说明为“争取到对应的人时出现”。

建议：展示一个合法状态对应的版本，或明确分栏展示两条路线；不得把所有条件强制判真。

### 2. 图鉴给出的结局攻略不完整（P1）

位置：`results.html:408` 附近的 `describeCond` 与 `results.html:462`。

- 血色长安用 `find` 只取首个同目标路由，遗漏“毁掉油罐也可成功”。
- 火起长安只显示拔刀，不展示“同路人不足 3 且没有毁油罐”的兜底前提。
- 共情劝降的 `trust.longbo >= 20` 未被翻译，显示为没有门槛。

建议：按路由顺序表达完整条件，支持同目标多条路径及 trust 条件，处理兜底对前面规则的排除。

### 3. 龙波相认场景的说话对象与信息顺序错误（P1）

位置：`src/data/scenes.js:1954`、`:2009`。

龙波面对张小敬说“张小敬你知道——他也在第八团，那时候他叫我萧哥”，把听者当作第三人。该段已自报“我是护旗的萧规”，下一屏却再次写玩家凭疤痕“认出来了”。

建议：改成面对故人的第二人称对话；在听过身世的路径上承接相认，其他路径才保留现场辨认。

### 4. 核心时间线没有统一（P1）

位置：`src/data/scenes.js:287`、`:291`、`:577`、`:583`、`:599`、`:613`、`:1712`、`:1905`。

- 子时开场限时“十二个时辰”，却同时要求“明日日出之前”；这不是同一个截止时间。
- 写“子时已过”后，后续多个过场、葛老节点仍标子时。
- 未时（项目定义 13—15 点）望楼正文写“暮色”，过场又写“晒了一整天，还留着一点白天的温度”。
- 申时还说“明天上元”，当晚却已上灯楼、子时引爆；需要交代这是灯会前破坏还是灯会当场袭击。

建议：先确定唯一的日期、当前时间及袭击时刻，再校正节点正文和倒计时。

### 5. 军械文书门控与已发生剧情冲突（P1）

位置：`src/data/scenes.js:1355`、`:1495` 附近。

香铺三条路线最终都会在 `h_si_doc` 读到“你翻开文书”，看清军械与崔器签收。午时“出示文书”仍只认最初选择产生的 `read_doc`，其他已经看完文书的玩家却收到“你还没看过”的未解锁提示。

建议：区分“早一步主动阅读”与“是否读过”的状态；若门槛是读过，必须在实际阅读后解锁。

## 其他明确问题

### 6. 人物维度标签显示 undefined（P2）

位置：`results.html:479`、`:532`。

声明 `dimLabel(key, letter)`，调用只传 `dimLabel(letter)`，函数读取的第二参数为空。浏览器已复现。改为单参数函数或正确传参。

### 7. 最相似人物与次席不是同一排名（P2）

位置：`src/data/mbti.js:319`、`:330`，`src/main.js:521`、`:531`。

主匹配是类型预设角色，契合度用绝对偏差；次席用 z-score 形状距离。实际可达结果：ENFP 主匹配鱼肠 81%，次席葛老 84%。两种百分比不可当作同一榜单的第一、第二。

建议：统一算法后排名，或分别命名“同型代表人物”和“特质形态相近人物”，不再叫次席。

复现：每个抉择取原数组零基下标，过场自动继续：
`0,1,2,1,2,1,0,0,2,1,1,0,2,0,0,1,1,1,1,3`。

### 8. 50/50 仍显示确定倾向（P2）

位置：`src/data/mbti.js:410`、`:412`。

实际路径 E/I 原始分 5，基线 4.916666666666666，偏移约 0.0833，百分比舍入为 50/50，`resolved` 却为 `ok`，显示 E 并不标“无偏好”。已有平局处理只处理浮点值真正相等，没覆盖展示舍入。

建议：保留足够小数并标弱倾向，或统一展示精度下的平局规则。

复现零基下标：`1,2,0,0,2,2,1,0,1,0,1,2,2,1,0,1,2,2,1,0`。

### 9. 六维分数的解释不符合计算公式（P2）

位置：`src/main.js:587`，`src/data/traits.js` 的 `normalize`。

实际是累计权重分 / 各节点最大可得权重分，并非选择次数占比。选项有 1、2、3 等不同权重，不能解释为“10 次机会选了 8 次”。建议改为“本局可得特质分的达成率”。

### 10. 部队身份仍残留两套口径（P2）

位置：`src/data/scenes.js:589`、`:629`、`:1686` 对比 `:871`、`:1950`。

主线和人物表已改第八团，回忆选项、腰牌及承接插段仍写第十团。若不是刻意安排两段军旅经历，应统一；当前文本未提供转换解释。

### 11. 开场与过场存在动作、服装及履历断裂（P2）

位置：`src/data/scenes.js:94`、`:121`、`:164`、`:209`、`:311`。

- 开场已写“站了起来”，谨慎选项过场却开头写“没有站起来”。
- “那两个字的门推开”指代不成立，建议直接写牢门或“长安”唤起的念头。
- 默认九年不良帅，谨慎变体改成十年。
- 换干净衣服仅在答应合作支路发生，后续要权过场却对所有来路写“那身干净衣裳”。

### 12. 血色长安缺少关键处置动作的因果桥（P2）

位置：`src/data/scenes.js:1905`、`:2085`。

阙勒霍多明确“全在灯楼底下”，结局却“被推下了灯楼”，没有搬运或位置变化。拔刀成功由同路人数或毁罐决定，正文也未交代哪种因素帮助成功。建议按成功原因补具体动作，统一油罐位置。

### 13. 未竟之局跨年缺少转场（P2）

位置：`src/data/scenes.js:2205`、`:2209`。

“三个月后”查案、案卷被压，紧接“上元节的灯又亮了”。如果是翌年上元，需要“又过了大半年／翌年上元”等明确时间桥。

### 14. 伤情与人员状态仍有未经路径支持的断言（P2）

位置：`src/data/scenes.js:1596`、`:1614`、`:2227`。

- 保护崔器路径先说他留在靖安司，紧接李必说“我就剩你一个了”，未交代崔器不能提供帮助的原因。
- 火起长安无条件指定左肩伤口，前文并未保证所有可达路径都有这一伤情。
- 该结局要求同路人不足 3，并不等于没有同路人。若其余人未赶到，需要交代阻隔原因，不能仅靠人数阈值推导“身后没有人”。

### 15. 人物资料提前泄露核心谜底，且与结局设定欠缺衔接（P2）

位置：`src/data/characters.js:9`、`src/main.js` 的 `renderSide`、`src/data/scenes.js:2095`。

开局侧栏直接展示主角完整 bio，其中已点明“萧规（龙波）”，削弱后面的身份辨认悬念。资料和前文强调“永无赦”，血色长安又直接获赦，缺少为何有例外的故事解释。这里指出的是文本内部承诺不一致，不对历史法律作判断。

## 表达与维护问题

- 长段人物背景直接塞进对话，包括括号中的主使人名、律名、组织名单，读起来像设定说明。尤其 `x_yin_cuiqi`、`x_xu_hear`，应拆成动作、短问答与必要回忆。
- “看了很久／没答／你没接话／转身走了”反复出现；不少过场只有停顿和气氛，没有新线索、行动后果或人物关系变化。建议保留真正有变化的段落，缩短功能重复的过场。
- README 玩法表仍写龙波信任 ≥30，实际为 ≥20；分布统计也已旧。`check:readme` 只核对选定字段，不能保证文档整体正确。
- 自动化中的“结构可达”“flag 被引用”“已人工确认白名单”都不能证明路径语义正确。应补上述互斥插段、门控与叙事状态、人物标签和结果排序的针对性回归。

## 建议处理顺序

1. 修图鉴的条件正文、触发规则和标签；统一结果页计分表述。
2. 校正时间线、相认顺序、读文书门控与油罐位置。
3. 清理部队身份、动作服装、伤情与跨年转场。
4. 按具体可达路径重读四个结局及条件变体，最后更新验收声明和 README。
